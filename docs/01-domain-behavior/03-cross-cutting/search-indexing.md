# Search Indexing & Discovery Surfaces (curated)

## Qué se indexa
- Listings (Published + eligible)
- Profiles (según privacy)
- Tags
- Places (si aplica)

## Cuándo se actualiza
- Publish/Unpublish/Archive listing
- Cambios relevantes de listing (título, tags, place, price) **NEEDS CLARIFICATION**
- Cambios de privacidad/eligibility

## Surfaces
- Search results
- Discovery feed
- Suggest feed
