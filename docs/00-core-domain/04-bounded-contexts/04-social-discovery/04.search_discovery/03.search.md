# Search (Búsqueda)

## Context/Goal
Definir la experiencia de búsqueda guiada por intención del usuario.

## Superficies de Search
1) **Global Search Bar** (navbar): busca en Listings/Profiles/Places
2) **Search within context**:
   - dentro de un Place (solo listings de ese place)
   - dentro de un Profile (solo listings/posts de ese profile)
   - dentro de una categoría/tag (solo subset)

## Modelo de query (producto)
Una búsqueda combina:
- **texto** (keywords)
- **filtros** (facets)
- **contexto** (ubicación, time window, preferencias)

Ejemplos:
- “masaje 60” + zona + hoy
- “cancha fútbol 5” + sábado + noche
- “dermatólogo” + cerca mío

## Result types (mezcla controlada)
MVP recomendado: resultados por secciones
- Top Listings
- Top Profiles
- Top Places
- (opcional) Tags/Services sugeridos

## Ranking (alto nivel, sin algoritmo)
Señales típicas:
- Relevancia textual
- Distancia/ubicación
- Disponibilidad próxima (solo para service listings, como metadata)
- Popularidad (clicks, bookings, follows)
- Calidad (completitud de listing, fotos)
- Preferencias del usuario (sigues al profile, historial)

> Reglas: Sponsored placement se etiqueta como “Sponsored” y respeta Access.

## UX: “No results”
- sugerir relajar filtros
- sugerir tags/categorías cercanas
- sugerir explorar “cerca mío”

## AC (Acceptance Criteria)
- Given un listing no visible por Access, then nunca aparece en resultados.
- Given un profile privado, then aparece con metadata mínima y CTA follow request.
- Given filtros de ubicación, then solo resultados dentro de zona/radio configurado.
