# Qué se indexa (Entidades buscables/descubribles)

## Context/Goal
Definir qué objetos entran en Search & Discovery y bajo qué condiciones.

## Tabla de entidades (MVP recomendado)
| Entidad | Buscable | Descubrible | Clave UX | Notas |
|---|---:|---:|---|---|
| Listing | ✅ | ✅ | Card con CTA Reservar/Comprar | Objeto promocionable |
| Profile | ✅ | ✅ | Card identidad + Follow | Respeta private/blocked |
| Place | ✅ | ✅ | Card con mapa/zona | Útil para “cerca mío” |
| Service/Product (concepto) | ✅ (facet) | ✅ (landing) | Categorías/etiquetas | No es objeto “comprable” sin Listing |
| Post | (opcional) | (opcional) | Card social | Recomendado fase 2 si no hay moderación sólida |

## Reglas de elegibilidad por entidad
### Listing
Aparece si:
- el viewer tiene permiso de verlo (Access)
- el Listing está publicado (no archivado)
- cumple políticas: geo (si aplica), stock (si product), disponibilidad (si service)

> Nota: “Próxima disponibilidad” puede mostrarse como metadata, pero no es el objeto indexado.

### Profile
Aparece si:
- no hay block (en ninguno de los sentidos)
- si es privado: mostrar metadata mínima (decisión de producto) + CTA follow request

### Place
Aparece si:
- el Place está asociado a un Profile visible o a Listings visibles
- respeta permisos (si un Place es privado/solo staff, no aparece)

## Facets principales (comunes)
- Categorías/Tags (ej: “Fútbol”, “Dentista”)
- Ubicación/zona (near me, ciudad)
- Precio (rango)
- Disponibilidad (hoy/esta semana) para services
- Tipo: service vs product
