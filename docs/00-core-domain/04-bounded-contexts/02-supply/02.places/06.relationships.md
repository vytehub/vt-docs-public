# Relationships

## Vista rápida
- **Profile** tiene **Places**
- **Listing** referencia un Place (o un conjunto de Places)
- **Booking/Event** referencia un Place (instancia final)
- **Timeline** “alberga” Events/Bookings, independientemente del Place

```mermaid
flowchart LR
  PR[Profile] --> PL[Place]
  SV[Service/Product] --> LI[Listing]
  LI -->|uses| PL
  LI --> BK[Booking]
  BK --> EV[Event]
  BK -->|occurs at| PL
  EV -->|in| TL[Timeline]
