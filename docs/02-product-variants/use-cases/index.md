# Use Cases

Esta carpeta reúne escenarios reales (personas y organizaciones) que queremos soportar con VyteMerge.

Cada caso incluye:
- **Objetivo de negocio**
- **Flujo principal**
- **Requisitos**
- **Mapping al Core Model** (Profile, Timeline, Service/Product, Listing, Slot, Event, Booking, Attendees, Order, Agreements/Access, Campaigns, Feed/Chat/Channels)
- **Edge cases**
- **Preguntas abiertas**
