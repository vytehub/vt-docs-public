# Visibility

## Objetivo
Permitir que el owner controle:
- cuánto “dónde” se muestra
- en qué momento
- y a quién

Sin romper:
- discovery
- confianza
- seguridad

---

## Niveles recomendados
### Public (dirección visible)
- útil para comercios/consultorios
- puede mostrar mapa y dirección completa

### Approximate (zona/barrio)
- ideal para domicilios / lugares sensibles
- en feed/marketplace muestra “zona”
- dirección exacta solo en booking confirmado

### Hidden (solo ciudad)
- muestra ciudad/área general
- dirección exacta solo para roles permitidos (owner/staff) o cuando se confirma la cita

---

## Place Visibility vs Access VisibilityMode
- **Place Visibility** controla “qué del lugar se puede mostrar”.
- **Access VisibilityMode** controla “cuánto del recurso en general se puede ver”.

Ejemplo:
- Podés ver un listing completo (BusyOnlyDetails),
  pero si el place está en modo Approximate, igual no ves dirección exacta hasta confirmar.

---

## Regla MVP recomendada
- Public discovery: nunca exponer dirección exacta si el place es “Approximate/Hidden”.
- Dirección exacta:
  - solo cuando el booking está **Confirmed**
  - y el actor tiene derecho a verla (Access).
