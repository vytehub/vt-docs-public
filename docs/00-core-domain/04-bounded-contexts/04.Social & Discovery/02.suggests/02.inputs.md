# Inputs (Signals)

## Señales principales (MVP)
1) **Agenda**
- próximos Events/Bookings
- ventanas libres entre eventos
- lugar asociado (si existe)

2) **Places**
- lat/lng + precisión
- timezone
- visibilidad (exacto vs aproximado)

3) **Listings disponibles**
- cercanía al place actual o del próximo evento
- disponibilidad cercana en tiempo
- tipo (service/product)

---

## Señales secundarias (Fase 2+)
- intereses/tags del usuario (Social/Tags)
- historial de interacción (clicks, saves)
- follows (providers favoritos)
- preferencias de horario / distancia máxima
- campañas patrocinadas (Campaigns)
